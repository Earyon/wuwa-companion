# Visuels du menu Résonateur

Wuthering Waves — Kuro Games. Quinze images issues des atlas locaux UiRole, RoleSkillTree et RoleDeviceList du correctif 3.6.13, lus sans modifier l'installation. Le découpage utilise les coordonnées de chaque sprite dans les données du jeu, puis une conversion WebP sans perte. Les pixels ne sont ni redessinés ni recolorés ; le navigateur applique les états et teintes de sélection. Comparaison avec les références publiques Encore et la vidéo utilisateur. Origines, coordonnées et empreintes dans `sources.json` ; procédure et limites dans `../../SOURCE_DATA.md`.
